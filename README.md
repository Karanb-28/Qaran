# Sofi-AI 💜
A sarcastic, Gen-Z styled AI chatbot built with Python, Hugging Face, and Gradio.

### 🚀 Live Demo
[Talk to Sofi here](https://huggingface.co/spaces/Qaran2834/Sofi-AI)

### 🛠️ Tech Stack
* **Language:** Python
* **Model:** Microsoft DialoGPT-medium
* **Interface:** Gradio
* **Hosting:** Hugging Face Spaces
