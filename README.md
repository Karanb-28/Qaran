# Sofi-AI 💜

A sarcastic, Gen-Z styled AI chatbot with a girlfriend personality and absolutely zero chill. Built with Python, DialoGPT, and a custom sass filter.

### 🚀 Live Demo
[Talk to Sofi here](https://qaran2834-sofi-ai.hf.space)

### ✨ Features
* **Girlfriend Identity:** Fixed the "sister" bug—she knows exactly who she is.
* **Sass Filter:** Automatically injects slang like *fr fr*, *vibe check*, and *💅*.
* **Speed Optimized:** Responses tuned for maximum speed on free cloud hardware.

### 🛠️ Tech Stack
* **Language:** Python
* **Model:** Microsoft DialoGPT-medium (Tuned to Temp 1.2 for more "unhinged" replies)
* **Interface:** Gradio (Luxury Purple Theme)
* **Hosting:** Hugging Face Spaces
